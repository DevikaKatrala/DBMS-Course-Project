## Project Description
A database management system for managing customers, vehicles,
service bookings, job cards, mechanics, spare parts, invoices,
and payments at a vehicle service centre.

## Technologies Used
- Python
- Tkinter
- MySQL
- mysql-connector-python

## UI Features
- View records across 12 tables
- Insert new records
- Delete selected records with confirmation
- Select related records using foreign-key dropdowns
- Validate inputs and display database errors
